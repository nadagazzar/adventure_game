Jungle Adventure Game
Final Project | DECI Python Track

A text-based survival RPG built with Python. Navigate 5 levels of the jungle, find hidden treasures, and survive dangerous encounters to win.

## How to Play
Navigate: Choose between the House, Cave, or Forest.

Survive: Encounter random enemies (Gorillas, Snakes, Bandits).

Decide: Fight (harder each level) or Run (safer, but watch for traps).

Win: Find the treasure in all 5 levels without losing your health.

## Technical Features
Procedural Logic: Randomizes treasure locations and enemy types.

Scaling Difficulty: Fight success rates decrease as you level up.

Input Validation: Robust handling of user choices to prevent crashes.

Game Loop: Features a "Play Again" mechanic and real-time health tracking.
